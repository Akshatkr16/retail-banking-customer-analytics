# Retail Banking Customer Analytics

## Overview
An exploratory data analytics and business intelligence project using a retail banking customer dataset. The project analyzes customer demographics, recorded account balances, regional distribution, job classifications, and customer joining trends.

## Tools Used
- Python
- Pandas and Matplotlib
- Jupyter Notebook
- Microsoft Power BI

## Dashboard Features
- **Executive KPIs:** Total customers, average recorded balance, and average age
- **Regional Analysis:** Customer distribution and average recorded balance by region
- **Customer Segmentation:** Distribution by job classification
- **Acquisition Trends:** Monthly customer joining patterns
- **Interactive Filters:** Region and gender slicers

## Key Findings
- The dataset contains 4,014 customer records.
- England has the largest customer count, with 2,159 customers.
- Wales has the highest average recorded balance, at approximately 42,390.
- White Collar is the largest job classification, with 1,955 customers.
- Recorded customer joining varies across the months represented in the dataset.

## Dataset
The project uses a sample UK bank customer dataset. The currency and business context of the recorded balance are not independently verified, so the analysis does not assign a currency or infer profitability.

## Repository Contents
- `data/` — Cleaned dataset
- `notebooks/` — Data cleaning and exploratory analysis
- `powerbi/` — Interactive Power BI report

## Disclaimer
This is an analytical portfolio project based on sample data. Findings describe the dataset and should not be interpreted as verified business outcomes or recommendations for a specific bank.
